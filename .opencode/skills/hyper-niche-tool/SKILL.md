## Tool Development Protocol
1. **Client-Side First**: Perform calculations instantly in TypeScript without server roundtrips.
2. **Mobile-First Layout**: Build 375px layout first, verifying touch target accessibility and font sizing before expanding to desktop grids.
3. **Theme Variables**: Use CSS variables for all visual primitives to ensure seamless Day/Night mode switching.
